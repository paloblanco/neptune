Neptune

v0.1.0

A lightweight JavaScript 3D game engine for small devs with little to no 3D experience. Wraps Three.js behind a clean, PICO-8-inspired API — build a complete game in a single file.

API Documentation GitHub
⚡

Simple by default

A working game loop is a dozen lines. No boilerplate, no config files.

🎮

PICO-8 inspired

Familiar update(dt) / draw() callbacks. State machine via plain function reassignment.

📦

One peer dependency

Three.js is the only required dependency. You control its version.

🕹️

60 FPS contract

Fixed-timestep accumulator handled internally. Write deterministic logic, not frame timers.

Install

npm install neptune-engine three

Import

import Neptune from 'neptune-engine';
